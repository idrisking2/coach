# Boulder Super Coach

Android-App für strukturiertes Bouldertraining mit Readiness, 10-Tage-Plan, Fingerlast-Steuerung, Technikdrills, MoonBoard-Tracking, Conditioning und Analyse.

## APK bauen

1. Öffne oben den Tab **Actions**.
2. Wähle **Build Android APK**.
3. Klicke **Run workflow**.
4. Warte, bis der Build grün ist.
5. Öffne den fertigen Workflow-Run.
6. Lade unten bei **Artifacts** `BoulderSuperCoach-debug-apk` herunter.
7. Entpacke das Artifact. Darin liegt `app-debug.apk`.
8. Kopiere die APK auf dein Android-Handy und installiere sie.

## Hinweis

Die App speichert Trainingsdaten lokal in der Android-WebView. Exportiere regelmäßig im App-Tab **Daten** deine JSON-Sicherung.
